This is a front-end prototype demonstrating login and role-based dashboard access for Manager and Employee accounts. The system uses hardcoded credentials and does not connect to a database.

Login Credentials:

Manager --> Email manager@make-it-all.co.uk, Password: Manager123, Manager Code: Code123

Employee --> Email employee@make-it-all.co.uk, Password Employee123

Instructions to Access Dashboards:

1. Open index.html in a modern web browser.

2. Go to the login page and enter the email and password for either the Manager or Employee account.

3. If logging in as a Manager, you will be prompted to enter the Manager Code (Code123). Enter the code to access the Manager Dashboard.
NOTE: This is the only way to access the manager dashboard, as the webiste does not save login information due to limit database access. 
Therefore, if you wish to view the manager dashboard, you must go back to the login page and enter the Manager credentials.

Click the “Dashboard” navigation item to view the Employee Dashboard (this works for all users).

The registration page is a static demonstration only and does not save any user information.
